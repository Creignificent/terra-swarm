# Customer Workflow

1. Customer arrives → Sales Agent qualifies
2. Diagnostics Agent profiles sample
3. Consortium Design Agent proposes solution
4. Pricing Agent generates quote
5. Compliance Agent clears
6. Finance Agent invoices
7. Sourcing + Fulfillment Agents ship
8. QA Agent releases
9. Customer Success Agent verifies performance
10. Feedback loops to Research and CRM

All steps follow the Perceive → Reason → Plan → Evaluate → Act → Verify → Learn loop.
